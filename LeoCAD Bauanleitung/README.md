# Bauanleitung – LeoCAD

Die Bauanleitung liegt im Format `.ldr` vor und kann mit **LeoCAD** geöffnet werden.

## Voraussetzung

Um die Bauanleitung zu öffnen, muss LeoCAD installiert sein:

- **Download:** [https://www.leocad.org](https://www.leocad.org)
- Verfügbar für Windows, macOS und Linux

## Datei

- `dolly.ldr` – Bauanleitung der Grundkomponenten: Horizontale Drehachse, Vertikale Drehachse und Gearboxen

> Das vollständige Lego-Modell befindet sich noch in der Konstruktion – allerdings sind damit bereits 90 % der Arbeit getan.
